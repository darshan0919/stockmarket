# scripts/pdf-corpus — build and verify the PDF extraction corpus

Corpus lives in `data/pdf-corpus/` (git-ignored and **never** synced: `data:push`/`pull`/`status` skip `pdf-corpus/` and `xbrl-corpus/` via `packages/jobs-runtime/lib/dataSyncPolicy.js`; this is study/testing/training material, not part of any persisted workflow). Plan and bars: `docs/PDF_OCR_EXTRACTION_PLAN.md` §3c, §8.
Run order (each step is resumable; download and truth are time-capped, so re-run until `remaining` is 0):

| Step | Command                                                                                                                                                        | Does                                                                                                             |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| 1    | `yarn pdf-corpus:universe -- --results a.jsonl,b.jsonl`                                                                                                        | Joins XBRL validation output with `company-master.json` -> `universe.jsonl` (sector, family, truth availability) |
| 2    | `yarn pdf-corpus:companies`                                                                                                                                    | Stratified company sample -> `companies.jsonl` with hash-stable train/dev/test split by company                  |
| 3    | `yarn workspace @stock/api bulk-filing-scan --companies-file data/pdf-corpus/companies.jsonl --out data/pdf-corpus/scan --types all --from 202409 --to 202609` | Lists filings of every type without per-company calls (`docs/BULK_FILING_SCAN.md`); re-run after a 429           |
| 4    | `yarn pdf-corpus:select-scan`                                                                                                                                  | Turns scan rows into `selection.jsonl` (keeps existing rows; hash-stable)                                        |
| 5    | `yarn pdf-corpus:download -- --concurrency 16 --budget-sec 120`                                                                                                | Downloads from S3, checks `%PDF-`, dedupes by sha256, classifies text/scanned/hybrid -> `manifest.jsonl`         |
| 6    | `yarn pdf-corpus:truth -- --concurrency 12 --budget-sec 110`                                                                                                   | Pairs Result PDFs with XBRL values -> `truth.jsonl`                                                              |
| 7    | `yarn pdf-corpus:verify` (`-- --lock` when ready)                                                                                                              | Integrity + stratum gate; locks the test split                                                                   |
| 8    | `yarn pdf-corpus:baseline -- --run-id baseline-v0` (`-- --summarize`)                                                                                          | Scores today's Result pipeline against the truth -> `runs/<id>.jsonl`                                            |
| 9    | `node scripts/pdf-corpus/gold.js select\|packets\|verify --pass A\|B\|queue\|tiebreak\|apply\|status`                                                          | Gold labels for non-Result types: two passes, script-verified quotes, tie-break, owner adjudicates the rest      |
| 10   | `node scripts/pdf-corpus/bench.js --run-id R --split dev --candidates "router;t3=ollama:qwen2.5:7b"` then `report.js --run-id R`                               | Benchmark the router and local models against XBRL truth; run on the Mac, see `docs/LOCAL_MODEL_EXTRACTION.md`   |

Do not run the older `list_docs.js` / `select_docs.js` (per-company Stockscans listing, rate-limit blocked): `select_docs.js` rewrites `selection.jsonl` and would drop scan-derived rows.
